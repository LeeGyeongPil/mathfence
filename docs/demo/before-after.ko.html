mathfence 끔

가격이 수식으로 짝지어졌고(강조 상자), 괄호 수식은 글자 그대로 남습니다.

The plan costs 5 per seat and the cluster fee is 1,200, so the total is 5n + 1,200.

With (n) seats the cost per seat is x = 5 + 1200/n.

Shell users can check it with echo $HOME.

mathfence 켬

가격은 글자로, 진짜 수식은 수식으로, 코드 조각은 그대로입니다.

The plan costs $5 per seat and the cluster fee is $1,200, so the total is $5n + $1,200.

With n seats the cost per seat is x = 5 + 1200/n.

Shell users can check it with echo $HOME.

x 강조된 기울임 상자 = 렌더러가 수식으로 본 부분
